# 3주차 - 셸 스크립팅
- 셸 스크립트를 사용하여 작업을 자동화하는 방법을 배움.
- Ollama와 Qwen을 이용해 로컬 AI 웹 서비스를 실행하는 실습을 함.

# 셸 스크립트
- 여러 명령어를 하나의 파일에 작성하여 순서대로 실행할 수 있게 해주는 것. 반복적인 작업을 할 때 편리하다.
- Qwen은 답변을 생성하는 AI 모델이고 Ollama는 모델을 실행하고 관리하는 도구이다.
- 스크립트는 실행 권한이 필요하며 환경변수로 프로그램 설정을 변경할 수 있다.

# 주요 명령어/실습

파이썬 웹 프로그램을 쉽게 실행하기 위해 `start.sh`를 작성했다.

```bash
#!/bin/bash
cd "$(dirname "$0")" || exit 1
exec python3 chat.py
```

- #!/bin/bash : 스크립트를 bash로 실행하도록 지정
- cd : 스크립트가 있는 폴더로 이동
- || exit 1 : 앞의 명령어가 실패하면 종료
- exec : 현재 셸 프로세스를 Python 프로그램으로 대체

```
nano : 파일 작성 및 수정
chmod : 파일 권한을 변경
./start.sh : 셸 스크립트 실행
chmod u+x start.sh :사용자에게 스크립트 실행 권한을 부여
```

`chmod u+x`로 실행 권한을 추가하고 `./start.sh`로 실행할 수 있다. 또 `export WEB_PORT=8080`처럼 환경 변수를 설정하면 웹 서비스가 사용할 포트도 변경할 수 있다.
