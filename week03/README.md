## 3주차
- 셸 스크립트를 사용하여 작업을 자동화하는 방법을 배움.
- Ollama와 Qwen을 이용해 로컬 AI 웹 서비스를 실행하는 실습을 함.

# 셸 스크립트
- 여러 명령어를 하나의 파일에 작성하여 순서대로 실행할 수 있게 해주는 것.
- 반복적인 작업을 할 때 편리함.

# 주요 명령어
```
nano : 파일 작성 및 수정
chmod : 파일 권한을 변경
./start.sh : 셸 스크립트 실행
chmod u+x start.sh :사용자에게 스크립트 실행 권한을 부여
```
# Qwen과 Ollama
- Ollama를 이용해 Qwen AI 모델을 준비하고 파이썬 웹 프로그램과 연결하는 방법을 배움.

매번 명령어를 입력하는 대신 start.sh 파일을 만들어 프로그램을 실행하도록 구성했음.
- #!/bin/bash : bash 폴더로 이동
- cd : 스크립트가 있는 폴더로 이동
- || exit 1 : 앞의 명령어가 실패하면 종료
- exec : 현재 셸 프로세스를 Python 프로그램으로 대체
