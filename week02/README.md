# 2주차

## 오늘 배운 내용

- 가상화(서버, 베어메탈.하이버파이저/컨테이너 비교)
- WSL2와 ubuntu를 이용하여 리눅스 환경을 구축
- Git을 통한 파일 관리
- Github저장소의 생성, 커밋, 푸쉬

## 새로 배운 명령어

```bash
!!        : 직전 명령어 재 실행
!ls       : 최근 실행한 ls 명령어 재실행
history   : 명령어 실행 기록 확인
head      : 파일의 앞 부분 출력
tail      : 파일의 뒷 부분 출력  
```
# Git 실습
```
git init                  : Git 저장소 생성
git status                : 파일 변경 상태 확인
git add .                 : 변경 사항 스테이징
git commit -m "메시지"    : 변경 내용 기록
git log                   : 커밋 기록 확인
git push                  : GitHub에 변경 사항 업로드
